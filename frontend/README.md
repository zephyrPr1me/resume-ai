# Resume AI — Frontend Documentation

Данный документ описывает архитектуру, стек технологий и принципы взаимодействия фронтенда с бэкендом для проекта **Resume AI**.

## 🛠 Стек технологий

- **Фреймворк:** [Next.js](https://nextjs.org/) (App Router, версия 16+)
- **UI Библиотека:** React 19
- **Язык программирования:** TypeScript
- **Стилизация:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Иконки:** `lucide-react` (интерфейсные иконки) и `@lobehub/icons` (логотипы AI-моделей)

---

## 🏗 Архитектура проекта

Проект построен по модульному принципу: логика отделена от визуального представления.

### Структура директорий
- `app/page.tsx` — Главная и единственная страница приложения. Отвечает за общую компоновку (Header, переключатель вкладок, уведомления об ошибках).
- `app/hooks/useAppState.ts` — **Сердце приложения**. Пользовательский хук, который инкапсулирует:
  - Управление состояниями (текст резюме, текст вакансии, выбранная модель, флаги загрузки).
  - Управление темой оформления (Dark/Light) с безопасной гидрацией.
  - Всю логику общения с бэкендом (выполнение API-запросов, обработка ошибок, `AbortController` для отмены устаревших запросов).
- `app/components/` — Переиспользуемые UI-компоненты:
  - `ModelSelector.tsx` и `ModelCard.tsx` — Выбор AI-модели с подгрузкой данных с сервера.
  - `SmartModelIcon.tsx` — Интеллектуальный рендеринг логотипов моделей на основе их ID.
  - `ResumeUploadAndPaste.tsx` — Зона ввода резюме (текст или Drag&Drop).
  - Вложенная папка `tabs/` (`AnalysisTab.tsx`, `MatchingTab.tsx`, `OptimizationTab.tsx`) — Содержимое разделов приложения, которые переключаются без перезагрузки страницы.
- `app/types/index.ts` — TypeScript интерфейсы для строгой типизации ответов сервера.
- `app/demoData.ts` — Заглушки данных. Используются как fallback, если бэкенд недоступен (Демо-режим).

## 🔗 Связка Frontend ↔ Backend

Фронтенд взаимодействует с бэкендом через REST API.

### 1. Конфигурация

Базовый URL бэкенда задается через переменную окружения `NEXT_PUBLIC_API_URL`. Если она не задана, по умолчанию используется `http://localhost:8000`.

### 2. Endpoints (Точки входа)

Все API-запросы выполняются внутри хука `useAppState.ts` и `ModelSelector.tsx`.

* **GET `/api/models-free/`**
  * **Где вызывается:** `ModelSelector.tsx` при монтировании компонента.
  * **Описание:** Запрашивает список доступных AI-моделей.
  * **Ответ:** Массив объектов `ModelInfo` (`id`, `name`, `context_length`).

* **POST `/api/analyze-resume-text/`**
  * **Где вызывается:** `handleAnalyzeResume` (Вкладка "Аудит").
  * **Тело запроса:** `{ "resumeText": "...", "model": "..." }`
  * **Описание:** Отправляет текст резюме на анализ (поиск сильных сторон, слабых зон, оценка ATS).

* **POST `/api/generate-profile-recommendations/`**
  * **Где вызывается:** `handleAnalyzeResume` (параллельно с аудитом).
  * **Тело запроса:** `{ "resumeText": "...", "model": "..." }`
  * **Описание:** Запрашивает рекомендации по улучшению профиля для вкладки "Оптимизация".

* **POST `/api/match-job/`**
  * **Где вызывается:** `handleMatchJob` (Вкладка "Мэтчинг").
  * **Тело запроса:** `{ "resumeText": "...", "jobText": "...", "model": "..." }`
  * **Описание:** Сравнивает резюме с вакансией, выдает процент совпадения и недостающие навыки.

### 3. Особенности сетевого взаимодействия

- **Передача `model`:** В каждом POST-запросе помимо текста передается параметр `model` (ID выбранной пользователем модели).
- **Graceful Degradation (Демо-режим):** Если сервер возвращает ошибку (500) или недоступен (CORS, таймаут), хук `useAppState` перехватывает ошибку и автоматически переводит приложение в "Демо-режим". В этом режиме пользователю показываются моковые данные из `demoData.ts`, чтобы интерфейс не ломался.
- **Отмена запросов (AbortController):** Если пользователь запускает новый анализ до того, как завершился предыдущий, или уходит со страницы, старые запросы мгновенно отменяются (`.abort()`), предотвращая утечки памяти и race conditions.

## 🚀 Запуск проекта

1. Установка зависимостей:
   ```bash
   npm install
   ```
2. Запуск в режиме разработки:
   ```bash
   npm run dev
   ```
3. Сборка для продакшена:
   ```bash
   npm run build
   npm run start
   ```
