### 1. Надежность и качество
- Добавить покрытие тестами:
  - unit-тесты для main.py (PDF-экстракция, валидация, парсинг JSON).
  - интеграционные тесты для эндпоинта `/upload/` через `httpx`/`pytest`.
  - фронтенд-тесты на взаимодействие загрузки, обработки ответа и ошибок.
- Ввести CI/CD:
  - запуск тестов, `ruff`/форматирование и проверка безопасности при PR.
  - автоматическое развёртывание на Vercel / Railway / Docker.

### 2. Работа с AI и устойчивость
- Сделать AI-ответ структурированным через схему API модели, а не только через `regex`/`json_repair`. Это снизит риск ошибок при некорректном выводе от Gemini.
- Добавить fallback-логику:
  - если модель вернула нечитаемый JSON, сохранить raw-ответ для отладки.
  - показывать пользователю более понятное сообщение об ошибке.
- Улучшить prompt:
  - четко описывать формат и примеры.
  - добавить инструкции для разных языков и для случаев, когда резюме короткое.

### 3. Расширение функциональности
- Поддержать дополнительные форматы резюме: `DOCX`, `TXT`, `RTF`.
- Добавить:
  - сравнение нескольких версий резюме,
  - экспорт результата в PDF/CSV,
  - сохранение отчёта пользователя.
- Реализовать «ATS-совместимость» и «ключевые слова вакансии»:
  - показать, какие термины совпадают,
  - какие фразы лучше добавить.

### 4. UI/UX
- Сделать интерфейс более доступным:

- Добавить прогресс-бар/статус загрузки и объяснения для разных состояний.
- Улучшить вывод результатов:
  - визуальные карточки с метриками,
  - выделение сильных и слабых зон,
  - подсказки «что улучшить в описании опыта».

### 5. Безопасность и валидация
- Проверять MIME-типы и расширения на бэкенде, а не только на фронтенде.

- Добавить проверку, что файл действительно PDF, прежде чем отправлять в AI.
